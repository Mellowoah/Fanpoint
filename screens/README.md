# Screenshots: MOCK MODE (sample data)

Every image in this folder was captured with **no API keys** (banner "MOCK MODE"): Qloo responses are Routed's
fictional fixtures (acts marked "(mock)", e.g. "Marigold Static" and its "(mock)" peers), and the LLM is the scripted
stand-in, so AI notes and the Plain AI panel are labelled SIMULATED. Cropped images (filter, trace, cards, rules,
sources) come from the same mock session. Census, OpenStreetMap and OSRM data are real.

Live captures (live Qloo data) are not committed: Qloo's terms keep response data out of a public repo. They live in
the gitignored `screens-live/` and are for the Devpost upload only. Retake these with a keyless server on :3100 and
`npm run screens` (see docs/DEPLOY.md).
